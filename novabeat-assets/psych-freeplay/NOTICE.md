# Psych Freeplay presentation assets

This folder contains the classic Psych Engine Freeplay menu's original background image, sprite-letter atlas, and menu sound effects, copied from the Psych Engine 0.7.3 repository.

- Source project: https://github.com/ShadowMario/FNF-PsychEngine
- Source revision: branch/tag 0.7.3
- Source license: Apache License 2.0 (included as LICENSE)

The NovaBeat code that loads and adapts these resources is maintained separately under upstream/Funkin/source/funkin/ui/freeplay. The assets are copied into the pinned FNF shared asset library by the Windows and Android build workflows.

These files remain attributed to their original project and contributors. NovaBeat is an independent project and is not endorsed by the Psych Engine contributors.
